# Deployment utilities

These scripts support the existing Jenkins/Ubuntu deployment. They are operator tools, not part of the application runtime.

| File | Purpose |
| --- | --- |
| `fetch-instance-config.sh` | Capture a sanitized inventory and selected configuration from a remote host |
| `generate-deployment-script.py` | Turn a captured snapshot into a host bootstrap script |
| `push-google-oauth-secret.sh` | Copy an OAuth client JSON file to the deployment host |
| `repair-live-deployment.sh` | Repair the known Jenkins/Nginx port and certificate layout |

Snapshots, archives, and OAuth JSON files are ignored. The checked-in `install-from-instance.sh` is a snapshot-specific example generated by this tooling. Review or regenerate it before running it as root; it reflects one machine's package and service state.

## Capture a host

The fetch script defaults to the historic EdgeLab host and SSH key. Override both rather than editing the script:

```bash
SSH_TARGET=user@example.com SSH_KEY=/path/to/key \
  deployment/fetch-instance-config.sh
```

The result is written below `deployment/instance-snapshots/`. Sensitive private keys, password databases, and live TLS key material are excluded, but the snapshot can still contain operational details and should remain local.

Generate a bootstrap script from a chosen snapshot:

```bash
python3 deployment/generate-deployment-script.py \
  deployment/instance-snapshots/<snapshot-directory>
```

## Upload Google OAuth credentials

Place the downloaded client JSON outside source control, then run:

```bash
GOOGLE_CLIENT_SECRETS_FILE=/absolute/path/client_secret.json \
  deployment/push-google-oauth-secret.sh
```

Check the script's target variables before use. The full Compose stack mounts `deployment/` read-only at `/opt/edgelab/deployment`, where FastAPI reads `google-oauth-client.json` by default.

## Application deployment

The normal application deployment is defined by the root `Jenkinsfile` and `docker-compose.yml`. General setup and security requirements are in [setup and deployment](../docs/setup-and-deployment.md).
